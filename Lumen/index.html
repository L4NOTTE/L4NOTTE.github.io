О браузере · Windows x64

Lumen.

Lumen — браузер для Windows с нативной логикой на Rust. Страницы отображает WebView2 на основе Chromium. Вкладки можно переносить между окнами, а фоновые страницы — выгружать из памяти.

Что умеет Lumen.

Вкладки, поиск и управление браузером реализованы на Rust. Настройки ниже относятся к версии для Windows.

Вкладки и сеанс

Перетащите вкладку за пределы панели, чтобы открыть её в отдельном окне. Ссылки средней кнопкой открываются в фоне. После перезапуска Lumen сначала загружает активную вкладку, а долго простаивающие страницы может выгружать из памяти.

Поиск, закладки и оформление

Центральное поле новой вкладки показывает подсказки из локальной истории. Панель избранного открывается поверх сайта. Можно выбрать тему, акцент, шрифт и фон, а масштаб сохраняется отдельно для каждого сайта.

Блокировка рекламы

Базовый режим блокирует известные рекламные домены. Усиленный режим использует списки фильтров и скрывает часть рекламных элементов на страницах. Режим можно сменить в настройках.

VPN для браузера

В разделе «Поиск и VPN» можно импортировать HTTPS-подписку или ключ VLESS. Lumen использует Xray-core для трафика браузера. Подключение зависит от протокола и параметров сервера.

Расширения и загрузки

В обычном окне Windows можно вставить ссылку из Chrome Web Store. Совместимость зависит от API WebView2. Список загрузок открывается через Ctrl + J. Там можно найти файл, открыть папку или отменить загрузку.

Lumen управляет окнами и вкладками на Rust. Страницы в Windows отображает Microsoft Edge WebView2 на основе Chromium.

Структура и стили

Движок разбирает HTML в дерево элементов и вычисляет CSS-стили для каждого элемента.

Установка

Для запуска нужны Windows x64 и Microsoft Edge WebView2 Runtime.

Установить

Закройте открытые окна Lumen и запустите LumenSetup.exe из последнего релиза.

Запустить из архива

Распакуйте Portable.x64.zip и запустите Lumen.cmd. Профиль будет храниться рядом с браузером.

Обновить

В установочной версии откройте «Настройки → Обновления». Для портативной версии скачайте новый архив.
