# Расписание ИПЭК — PWA (Android + iPhone)

Статический сайт: ни базы, ни внешних сервисов (шрифт Manrope лежит в `fonts/`), поэтому работает на любом хостинге в России и под белыми списками.

## Установка на сервер
1. Загрузите всё содержимое папки на хостинг по **HTTPS** (без HTTPS service worker и установка не работают; `localhost` — исключение).
2. Откройте сайт. Android/Chrome предложит «Установить»; на iPhone: Safari → «Поделиться» → «На экран “Домой”» (подсказка появится сама).
3. Файлы `sw.js` и `schedule.json` не кэшируйте на сервере (`Cache-Control: no-cache`), остальное — на любой срок.
   - Nginx: `location ~ ^/(sw\.js|schedule\.json)$ { add_header Cache-Control "no-cache"; }`
   - Тип для манифеста: `application/manifest+json` (или `.webmanifest`).

## Обновление расписания
Заменяйте `schedule.json` (формат: `{"updated": ISO-время, "days": {"2026-11-09": {"t": {"1": ["08:30","10:00"], …}, "l": [["Группа", пара, "Предмет", "Препод1/Препод2", "кабинет", подгруппа?], …]}}}`). Приложение подхватит его при следующем открытии, офлайн покажет последнюю сохранённую версию. При правке кода поменяйте `V` в `sw.js` (`ipek-v2`), тогда пользователи увидят «Доступна новая версия».

## Демо
`index.html?now=2026-11-09T11:15` — подставить «сейчас» (пара, идущая сейчас, подсвечивается мятным `#15d218`). Без параметра берётся реальное время.
